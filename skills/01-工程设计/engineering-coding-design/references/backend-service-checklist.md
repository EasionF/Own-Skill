# 后端服务与 API 设计检查表

用于后端服务、API、平台服务、微服务、单体服务和内部系统。

## 1. 服务边界

- 服务负责的业务能力。
- 服务不负责的能力。
- 上游调用方。
- 下游依赖。
- 数据所有权。
- 同步和异步边界。

## 2. API 设计

- 资源模型或操作模型。
- 请求和响应 schema。
- 认证与授权。
- 错误码和错误体。
- 幂等键。
- 分页、排序、过滤。
- 版本策略。
- 兼容策略。
- OpenAPI 或等价契约。

## 3. 数据与事务

- 数据库选择。
- 表或集合设计。
- 事务边界。
- 一致性要求。
- 锁和并发控制。
- 索引与查询路径。
- 审计字段。
- 软删除或归档策略。

## 4. 异步与后台任务

- 队列或任务系统。
- 消息 schema。
- 消费幂等。
- 重试和死信。
- 延迟任务。
- 任务可观测性。
- 任务取消和补偿。

## 5. 可靠性

- 超时。
- 重试。
- 熔断。
- 限流。
- 降级。
- 健康检查。
- 启动和关闭顺序。
- 数据恢复。

## 6. 安全

- 身份认证。
- 授权模型。
- 租户隔离。
- 输入校验。
- 敏感字段保护。
- Secret 管理。
- 审计日志。
- 管理接口保护。

## 7. 运维与部署

- 环境变量。
- 配置分层。
- Migration。
- 灰度发布。
- 回滚。
- 监控指标。
- 告警。
- Runbook。

## 8. 验收

- 正常 API 路径。
- 错误 API 路径。
- 权限边界。
- 并发和幂等。
- 迁移前后兼容。
- 下游依赖失败。
- 可观测性完整性。
