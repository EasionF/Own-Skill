# 关键设计决策记录

只记录影响架构、接口、数据、安全、依赖、成本或长期维护的决定。不要为琐碎实现细节写决策记录。

## 决策记录格式

```text
决策：

背景：

约束：

采用方案：

原因：

影响范围：

风险：

后续注意事项：
```

## 需要记录的决策

- 架构分层或模块边界。
- 数据模型和数据所有权。
- 公共接口、API、MCP tool 或事件契约。
- 新依赖、新存储、新队列、新外部服务。
- 权限、安全、审计模型。
- 迁移、兼容、灰度、废弃策略。
- AI 项目的 model、tool、memory、retrieval、eval 关键策略。

## 不需要记录的决策

- 局部变量命名。
- 小范围格式调整。
- 明显遵循现有模式的实现细节。
- 不影响接口、数据、安全、依赖或维护成本的内部改动。
