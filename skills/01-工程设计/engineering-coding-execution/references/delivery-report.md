# 交付说明格式

最终答复保持简洁，但必须覆盖结果、验证和风险。

## 简单任务

```text
已完成 [目标]，主要改动是 [简述]。

验证：[命令或检查] 通过。
```

## 标准任务

```text
已完成 [目标]。

主要改动：
- [改动 1]
- [改动 2]

验证：
- [命令/检查]：通过
- [命令/检查]：通过

残余风险：
- [如果没有，写无明显残余风险或说明未覆盖项]
```

## 无法完整完成

```text
当前未能完整完成 [目标]。

已完成：
- [已完成部分]

阻塞：
- [具体原因]

已验证：
- [已运行检查]

下一步：
- [最小可继续动作]
```
