Core engine

Anti-Slop Engine

AI defaults are the visual average of every SaaS landing page ever shipped. cc-design refuses the purple gradient, the rounded card with a left accent border, the emoji-as-icon, the SVG face with five crooked features — and replaces them with decisions a designer would defend.

Expert critique

Five-Question Test

Every element is audited against five questions borrowed from senior design review — if one fails, it does not ship.

Cover the text — is the subject still recognizable?
Swap the client name — does it still hold?
Does every element earn its place?
Is there a more concise way?
Does it serve the user, or the designer?

How it works

Three steps. No prompt engineering required.

01 · TRIGGER

Say it like a person.

In trae, just say「做个原型」「做个PPT」「做个好看的」. No magic incantation, no role-play preamble.

> 做个原型，咖啡品牌落地页
02 · DESIGN

cc-design picks a style, applies anti-slop, generates variants.

A fallback advisor surfaces three differentiated directions — random-roulette, real-world reference, and a top designer's philosophy — so you choose from real visuals, not from a text list. The anti-slop engine runs on every element. Variants are produced across color, type, and layout for you to mix.

Style match Anti-slop audit 3 variants Five-question test
03 · EXPORT

Ship in the format the moment needs.

HTML prototype for review, PPT for the meeting, MP4 with audio for the launch, GIF for the PR description, PDF for the record.
