## 文档名称

Brand PPTX Outline Skill 模块说明

Author: Wang Wei Yuan
Time: 2026-03-30

## 适用范围

用于说明大纲生成 skill 的输入、模型调用路径、输出结构和审查重点。

## 功能数据流转

输入主题及可选的受众、用途、语气、重点  
-> 构造提示词  
-> 调用模型服务或使用 dry-run 占位模式  
-> 归一化大纲字段和页面角色  
-> 按需写出 `outline.json`  
-> 返回结构化结果

## 详细代码模块

- `scripts/main.py`
  负责提示词构造、JSON 提取、结果归一化、async 运行入口和 CLI 入口。

## 审查要点

- 检查必填字段和默认值是否正确。
- 检查页面角色和页数归一化逻辑。
- 检查模型依赖、异常处理和输出文件写入行为。
