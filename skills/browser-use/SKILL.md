# Browser Use

当需要从本机浏览器历史中提取工作证据时使用本 skill。

## 工作流

1. 先检查默认历史记录路径：
   - Chrome：`%LOCALAPPDATA%\Google\Chrome\User Data\Default\History`
   - Edge：`%LOCALAPPDATA%\Microsoft\Edge\User Data\Default\History`
2. 如果浏览器可能还开着，不要直接查询原始数据库。
   - 先复制一份 `History` 到临时路径
   - 对复制后的文件执行查询
3. 只保留当天访问记录。
4. 将记录分成以下几类：
   - 工作检索
   - 文档学习
   - 模型/方案调研
   - 可能相关但证据不足
   - 明显无关
5. 只保留能支持工作结论的条目。
6. 返回紧凑总结，而不是原始 URL 堆砌：
   - 主题
   - 代表性页面
   - 可能用途
   - 置信度

## 规则

- 浏览器历史只是辅助证据，不是最终结论。
- 不要把重复搜索当成多项工作成果。
- 优先按主题分组总结，不要直接输出长 URL 列表。
- 如果 Edge 历史缺失，要明确说明，而不是默认 Edge 没被使用。
- 如果用户实际 Profile 路径不是默认路径，要说明证据覆盖可能不完整。

## 输出格式

需要时按以下中文标题组织输出：

- 可确认的工作相关浏览
- 可能相关但证据不足
- 明显无关，已排除
- 对日报可贡献的信息

## 交接边界

- 浏览器历史需要纳入日报证据时，应优先配合 `daily-report-evidence` 使用。
- 本 skill 不直接填写表单。
- 本 skill 不直接输出最终日报正文。
