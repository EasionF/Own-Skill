02 · Problem

The AI Design Problem

AI-generated designs all look the same. Purple gradients, rounded cards, emoji icons, generic SaaS templates. This is “AI slop” — and it is getting worse.

01

Generic Aesthetics

Most AI tools default to the same visual language. Every output converges on the average of training data, carrying no brand signal at all.

02

No Conceptual Root

Designs do not come from content, they come from templates. Without a conceptual root, pages are decorated containers, not decisions.

03

Unstable Output

Same prompt, different results, no quality floor. There is no predictable baseline — every run is a lottery on taste.

Problem 02 / 08

03 · Solution

The cc-design Approach

cc-design makes AI in trae IDE behave like a designer who happens to write code — not a code generator that happens to make pages.

01

Designer, Not Generator

Asks “what is this page for?” before writing code. Form follows content; every element earns its place or is removed.

02

Anti-Slop Engine

15+ explicit rules to avoid AI default aesthetics — purple gradients, rounded cards, emoji decoration, uncanny SVG imagery.

03

Style Library

50+ curated styles with real design references. Each style carries provenance, not invented aesthetics.

04 · Anti-Slop

Anti-Slop Engine

15+ rules to keep AI output from looking like AI output.

Rule Blocks Why Example
No Purple Gradients Mesh / rainbow gradients AI default signature Use oklch from brand color
No Rounded Cards + Left Border Generic dashboard look AI Dashboard signature Use real layout decisions
No Emoji Decoration Emoji as icons Lazy decoration Use CSS geometric shapes
No SVG Imagery Drawn people / scenes Uncanny valley Use placeholder + label
No Default Aesthetic Self-style defaults Unconscious slop Five-question test

06 · Workflow

How It Works

Three steps, from intent to export — no sign-up, no configuration, runs inside trae IDE.

01 · TRIGGER

Trigger

In trae IDE, say “做个原型”, “做个PPT”, “做个HTML页面”. cc-design picks up the intent.

02 · DESIGN

Design

cc-design selects a style, applies the anti-slop engine, and generates 3+ variants for side-by-side comparison.

03 · EXPORT

Export

HTML · PPT · MP4 · GIF · PDF. Single-file output, no external dependencies.
