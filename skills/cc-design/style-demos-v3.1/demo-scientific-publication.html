MindEcho: AI-Powered Emotion Tracking and Cognitive Reshaping in Digital Mental Wellness

Lin Chen1, Arjun Mehta2, Sofia Rinaldi1,3, Hiroshi Tanaka2, Elena Vogt1,*
1 Institute for Computational Mental Health, University of Zürich, CH-8050 Zürich, Switzerland
2 Department of Human-Centered AI, Kyoto Institute of Technology, Kyoto 606-8585, Japan
3 Affective Computing Lab, Politecnico di Milano, I-20133 Milano, Italy
* Correspondence: e.vogt@ijap.ai  |  ORCID: 0000-0002-1487-9931
Abstract The proliferation of consumer mental-health applications has outpaced the empirical evaluation of their core mechanisms. We present MindEcho, a mobile application that combines transformer-based emotion classification of unstructured journal entries with a closed-loop cognitive–behavioural therapy (CBT) micro-intervention engine, and an anonymous client-side encrypted vault for longitudinal self-report data. Across an 8-week randomised controlled study (N = 214), participants using MindEcho exhibited a 28.4% reduction in negative-emotion index relative to a waitlist control (Cohen's d = 0.62, 95% CI [0.34, 0.89]), with full retention of cryptographic privacy guarantees. We detail the system architecture, the CBT reshaping pipeline, and the AES-256-GCM vault design, and discuss implications for evidence-based digital wellness tools.1–3
Keywords affective computing · CBT · differential privacy · mobile health · self-supervised learning

1. Introduction

Digital mental-health interventions have expanded rapidly in the past decade, yet meta-analytic evidence suggests that fewer than 20% of commercially available applications have been evaluated in any randomised trial.1,2 Three structural barriers limit the evidentiary value of this ecosystem: (i) emotion inference is typically opaque and non-longitudinal; (ii) intervention content is delivered statically, decoupled from the user's current affective state; and (iii) the sensitivity of self-report data discourages both sharing and independent audit.3

MindEcho addresses these barriers through an integrated pipeline in which the same affective signal that drives analytics also triggers short, evidence-based CBT micro-entries, while all raw inputs remain on the client device under user-held keys. This paper (a) specifies the architecture, (b) reports results of an 8-week RCT, and (c) releases the cryptographic vault specification for independent review.a

2. Methods

2.1 AI Emotion Tracking

Free-form text and optional voice journal entries (mean 71.3 tokens, SD = 44.6) are processed on-device through a distilled 6-layer transformer (MindEcho-mini, 28M parameters) fine-tuned on a merged corpus of DAIC-WOZ, EmoBank, and an in-house licensed set of 84k anonymised entries. Inference produces a 7-class Plutchik label with a calibrated confidence score; entries below τ = 0.55 are flagged for human-in-the-loop review rather than discarded.4

2.2 Cognitive Reshaping (CBT-based)

When a negative-valence entry is detected with confidence ≥ τ, the reshaping engine selects one of four CBT micro-interventions — cognitive restructuring, behavioural activation, grounding, or thought-record — ranked by a contextual bandit trained on within-user response history. 2.3 Anonymous Vault

All raw journal entries are encrypted client-side before they ever touch persistent storage; the server stores only opaque ciphertext and an opaque user handle. Keys are derived from a user passphrase via Argon2id (memory = 64 MiB, iterations = 3, parallelism = 4) and never leave the device. Listing 1 shows the canonical encrypt-then-MAC path.5,6

// MindEcho vault — encrypt-then-MAC (AES-256-GCM)
const iv  = crypto.getRandomValues(new Uint8Array(12));
const key = await crypto.subtle.deriveKey(
  { name: 'Argon2id', m: 64*1024*1024, t: 3, p: 4, salt },
  baseKey,
  { name: 'AES-GCM', length: 256 },
  false, ['encrypt', 'decrypt']
);
const ct = await crypto.subtle.encrypt(
  { name: 'AES-GCM', iv },
  key, utf8.encode(entry)
);
// store: { iv, ct, tag } — server sees opaque bytes only
vault.put({ iv, ct });

3. Results

Of 248 screened participants, 214 were randomised (MindEcho n = 107; waitlist n = 107); 201 (94.0%) completed the 8-week protocol. The MindEcho arm showed a monotonic decline in weekly negative-emotion index, diverging from the control arm from week 3 onward (Figure 2). The between-arm difference at week 8 was 18.6 points (95% CI [11.2, 26.0], p < 0.001), corresponding to a 28.4% relative reduction.2,7 No serious adverse events were reported; three participants withdrew citing notification frequency.
