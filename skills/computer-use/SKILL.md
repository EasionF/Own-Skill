# Computer Use

本 skill 只用于最后一层 UI 执行，不负责推断内容。

## 前置条件

在使用本 skill 前，必须已经明确：

- 目标页面或应用已经打开，或者至少可达
- 报告内容已经确认
- 不清楚的事实已经和用户确认完毕

如果任一条件不满足，就停止，回到 `daily-report-evidence`。

## 工作流

1. 先识别目标 UI 和需要填写的字段。
2. 将已经确认的内容映射到对应字段：
   - 今日完成工作
   - 未完成工作
   - 未完成原因
   - 需协调工作
   - 今日学习内容
3. 一次只填写一个字段。
4. 每填完一个字段都做一次确认：
   - 内容是否落到了正确输入框
   - 是否误覆盖了其他字段
5. 最终提交前做一次整体复核：
   - 所有栏目都在
   - 原文措辞没有被改坏
   - UI 操作过程中没有新增编造内容

## 规则

- 不要为了填满表单而编造缺失内容。
- 如果字段被遮挡、被禁用或映射不清，停止并明确说明阻塞点。
- 优先使用确定性、最少步骤的操作。
- 如果无法直接填写页面，就返回可直接复制的最终文本。

## 失败处理

- 如果页面没打开，明确说明当前缺少页面状态。
- 如果表单结构和预期不同，先总结可见字段；只有在映射不清时才请求确认。
- 如果当前环境无法操作页面，就退回到“返回最终文本”的方案。
