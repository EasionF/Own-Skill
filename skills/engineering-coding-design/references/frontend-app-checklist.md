# 前端应用与交互工具设计检查表

用于 Web 应用、桌面应用、移动 Web、管理后台、可视化工具和交互式 AI 工具。

## 1. 用户与任务

- 目标用户。
- 高频任务。
- 关键路径。
- 空状态。
- 加载状态。
- 错误状态。
- 权限受限状态。
- 离开与恢复场景。

## 2. 信息架构

- 页面层级。
- 导航结构。
- 主要视图。
- 详情视图。
- 编辑视图。
- 搜索、筛选、排序。
- 批量操作。
- 状态反馈。

## 3. 状态管理

- 本地 UI 状态。
- 服务端数据状态。
- 表单状态。
- 乐观更新。
- 缓存。
- 同步冲突。
- 撤销或恢复。

## 4. 数据契约

- API 请求。
- API 响应。
- 错误体。
- 分页和增量加载。
- 实时数据。
- 文件上传下载。
- 数据校验。

## 5. 交互与可用性

- 表单验证。
- 禁用态。
- 确认动作。
- 危险操作。
- 快捷操作。
- 可访问性。
- 响应式布局。
- 长文本和极端数据。

## 6. 性能

- 首屏加载。
- 路由拆分。
- 列表虚拟化。
- 图片和资源优化。
- 避免重复请求。
- 大数据渲染。
- 离线或弱网策略。

## 7. 安全

- XSS 防护。
- CSRF 场景。
- Token 存储。
- 权限隐藏与后端授权边界。
- 敏感信息展示。
- 第三方脚本风险。

## 8. 可观测性

- 前端错误上报。
- 用户行为事件。
- 性能指标。
- API 失败率。
- Trace 关联。
- 关键流程漏斗。

## 9. 验收

- 核心路径可完成。
- 表单与错误路径正确。
- 权限状态正确。
- 移动端和桌面端可用。
- 极端数据不破坏布局。
- API 失败有可恢复体验。
