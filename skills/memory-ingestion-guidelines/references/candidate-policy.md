# 候选记忆策略

## 1. 写入类型

### factual

用于稳定事实：

- 环境约束。
- 服务端口。
- 仓库结构。
- 配置约定。
- 已确认接口行为。

### procedural

用于可复用流程：

- 修复步骤。
- 验证流程。
- 调试路径。
- 安装和接入步骤。
- 失败恢复路径。

## 2. candidate_payload 内容

包含：

- 结论。
- 适用条件。
- 证据。
- 验证方式。
- 影响范围。
- 后续注意事项。

避免：

- 大段日志。
- 不必要的代码全文。
- 未脱敏数据。
- 无上下文短句。

## 3. source_ref

来源应可追溯：

- 文件路径。
- 测试报告。
- 命令结果。
- 设计决策。
- 用户确认。
