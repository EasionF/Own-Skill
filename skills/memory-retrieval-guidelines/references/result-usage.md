# 读取结果使用

## 1. 使用优先级

- 当前用户明确输入优先。
- 当前代码和环境证据优先。
- 实时验证结果优先。
- memory 结果作为辅助上下文。

## 2. 可直接使用

- 明确的历史设计决策。
- 已验证的环境约束。
- 与当前 fingerprint 匹配的 procedural 经验。
- 已确认的失败模式和修复流程。

## 3. 只能作为线索

- fingerprint mismatch 的 procedural 经验。
- 未验证 candidate。
- 与当前代码版本不一致的历史结论。
- 缺少来源或验证状态的记忆。

## 4. 冲突处理

- 发现冲突时说明冲突来源。
- 优先检查当前代码、配置和测试。
- 不用 memory 覆盖当前明确证据。
